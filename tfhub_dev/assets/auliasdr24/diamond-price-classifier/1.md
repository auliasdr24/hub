## Deskripsi Model

Model ini menggunakan arsitektur neural network dengan:
- **Input**: Fitur numerik (carat, depth, x, y, z) dan fitur kategorikal (color, clarity)
- **Feature Columns**: Numeric columns, categorical columns dengan indicator, dan embedding columns
- **Arsitektur**: 
  - Dense(128, relu)
  - Dense(128, relu)
  - Dropout(0.1)
  - Dense(1) untuk output biner

## Cara Menggunakan

```python
import tensorflow_hub as hub
import tensorflow as tf

# Load model dari TensorFlow Hub
model = hub.load('https://tfhub.dev/auliasdr24/diamond-price-classifier/1')

# Siapkan input features
features = {
    'carat': tf.constant([0.5, 1.2]),
    'depth': tf.constant([60.0, 65.0]),
    'x': tf.constant([5.0, 6.5]),
    'y': tf.constant([5.1, 6.6]),
    'z': tf.constant([3.0, 4.0]),
    'color': tf.constant(['E', 'G']),
    'clarity': tf.constant(['SI2', 'VS1'])
}

# Lakukan prediksi
predictions = model(features)
print(predictions)
